# О проекте:

- Приложение предназначено для автоматизации специальной оценки профессиональных рисков на основе модифицированного метода весовых коэффициентов Файна-Кинни (разработан Фрезе Т.Ю.).
- Данные об опасностях, опасных событиях и мерах профилактики для оценки взяты из Приложения 1 Приказа Минтруда РФ от 29.10.2021 N 776н "Об утверждении примерного положения о системе управления охраной труда"
- Проект написан на чистом Python с использованием PySide6

---

# Использование

- Скачайте последний релиз исполняемого файла AURA;
- Поместите исполняемый файл в рабочую папку;
- Создайте ярлык на рабочем столе *(не обязательно)*
- Перед началом работы убедитесь, что вы зарегистрироаны на омашнем сайте AURA и приобрели подписку;
- Авторизуйтесь в приложении перед началом работы
